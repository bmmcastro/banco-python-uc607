As dúvidas mais normais sobre o sistema, com respostas diretas.

Não. É um projeto de formação (UC00607) — os saldos e as transferências existem apenas na base de dados SQLite do sistema (banco.db).

O sistema vem com duas contas de demonstração: bruno / bruno123 e ana / ana123. Também podes criar a tua própria conta no homebanking — a password precisa de 6 a 10 caracteres, com pelo menos 1 letra e 1 número.

Cada conta recebe um IBAN único gerado pelo sistema: PT50 seguido de um número. Para transferir basta escrever os números (ex.: 0002) — se escreveres o IBAN completo também funciona: o sistema mete as maiúsculas e tira os espaços sozinho.

O sistema mostra sempre o dono do IBAN antes de confirmar a transferência. Só depois do "sim" é que o valor sai da conta. Também não deixa transferir para a própria conta nem valores acima do saldo.

Num ficheiro SQLite gravado sempre a seguir a cada operação. O histórico da conta pode ser exportado para um ficheiro CSV com o botão "Exportar CSV" na página da conta.
